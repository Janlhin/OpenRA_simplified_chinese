# OpenRA 汉化组 RASC 术语对齐报告

> 目的：把 CastleJing/OpenRA_rasc（汉化组 RA 汉化，基于 2020 release）拉下来，与我们的
> `openra-zh-cn`（基于 playtest-20260222 Fluent 化引擎）做一轮术语比对，判断是否重复造轮子、
> 哪些译法可借鉴。

## 一、仓库结构核实（关键结论）

- RASC 仓库 **没有任何 `.ftl` 文件**（Glob 返回空）→ 证实它是 **pre-Fluent 旧式汉化**：
  中文直接内嵌在 `mods/rasc/rules/*.yaml` 的 `Name:/Tooltip:` 字段里，UTF-8 编码。
- 单位/建筑用**英文 ID 作锚点**（如 `MIG`、`HIND`、`MCV`、`AFLD`），只把下面
  `Tooltip/Name` 改成中文，ID 保留。这正是我们对齐的桥梁。
- 全仓提取到 **1553 条中文记录**（226 条 `Name` 字段），集中在单位/建筑/战役/界面。

**印证了前面的判断**：汉化组产物基于 2020 引擎，架构与我们的 Fluent 体系不同，
**不能直接套用**；但其译文字面（术语共识）可直接当参考基线。

## 二、与我们 ra 译文的比对

- 我们侧：扫描 `files/` 下 **162 个 .ftl**。
- RASC 侧：提取 `mods/rasc/rules/` 下命名类字段（Name/Tooltip）共 **199 条短名称候选**。

| 类别 | 数量 | 含义 |
|---|---|---|
| 完全一致 | 44 | 我们与汉化组叫法相同 |
| 我们更短（汉化组用全称） | 28 | 汉化组信息量更大，可借鉴 |
| 我们更长 | 20 | 我们描述更细 |
| 无对应 | 107 | 详见下，多为详略/用字差异 |

## 三、关键澄清：不是漏译

抽查 `actor-mig / actor-mcv / actor-afld` 的真实内容，确认**我们的 ra 单位名全覆盖**：

| 单位 | 我们 `.name` | 汉化组 RASC |
|---|---|---|
| MIG | 米格攻击机 | 米格战机 |
| MCV | 移动建造车 | 移动基地车 |
| AFLD | 机场 | 战地机场 |
| HIND | 雌鹿 | 雌鹿武装直升机 |
| TRAN | 支努干（已修） | 支努干运输机 |

"无对应"那 107 条，绝大多数是**详略/用字差异**，并非英文残留。
（这也反向验证了之前全量审计"残留英文仅 26 条且均为品牌/按键名"的结论是成立的。）
