## ① PS1 一键安装（推荐）

**前提**：Windows 10 / 11，系统自带 PowerShell 5.1；先关掉 OpenRA 三个 exe 的窗口；zip 解压到英文路径（如 `D:\OpenRA_CN`）。

1. 右键 `setup.ps1` → **使用 PowerShell 运行**
2. 菜单输入 `1` → 回车
3. 按提示启动游戏

菜单：`1` 安装 · `2` 还原英文 · `3` 校验是否卸干净

安装器自动完成：定位游戏目录 → 备份 → 覆盖 208 个文本 → 部署两个中文字体 → 逐文件 SHA-256 校验。
备份在 `<游戏目录>\_zhcn-backup\<时间戳>\`，还原靠它；卸载完成后可安全删除。

| 参数 | 作用 |
|---|---|
| `-Target "D:\Games\OpenRA"` | 指定游戏目录（自动探测失败时） |
| `-Uninstall` | 还原英文 |
| `-Verify` | 校验是否卸干净 |
| `-DryRun` | 只预览要改哪些文件，不写入任何文件 |
| `-FontPath "D:\yourfont.ttf"` | 换字体 |
| `-Yes` | 全部按“是”处理 |

## ③ 手动安装

适用：不想跑脚本，或公司电脑用组策略禁用了 PowerShell。**没有任何校验，四步顺序不能错。**

**第 1 步：备份**

把 `<游戏目录>\mods` 整个复制到别处（约 100 MB）。

**第 2 步：先放字体**

把本包 `fonts\` 两个文件复制到 `<游戏目录>\mods\common\`：
`NotoSansSC-Regular.ttf`、`NotoSansSC-Bold.ttf`

**第 3 步：覆盖文本**

把本包 `files\mods\` 的全部内容按同名路径覆盖到 `<游戏目录>\mods\`
（208 个，其中 12 个是新增：`common\fluent\ingame-debug.ftl` 与 11 个 `d2k\maps\*\map.ftl`）

**第 4 步：启动游戏**

按提示选 `RedAlert.exe` / `TiberianDawn.exe` / `Dune2000.exe`。

> 顺序反了会怎样：先覆盖文本、后放字体 → `mod.yaml` 已指向 NotoSansSC 但文件不存在，引擎**直接报错退出**（不是变方块）；只放字体、不覆盖文本 → 能进游戏，但界面仍是英文。

**自检**：`<游戏目录>\mods\common\` 下应同时有 `NotoSansSC-Regular.ttf`、`NotoSansSC-Bold.ttf` 与 `fluent\ingame-debug.ftl`。

**还原**：把第 1 步备份的 `mods` 覆盖回去，再删掉那两个 `NotoSansSC-*.ttf`。

## ④ 问题排查

| 现象 | 原因与处理 |
|---|---|
| 界面全是方块 | 字体没生效。`mods\common\` 缺 `NotoSansSC-*.ttf`，或 `mod.yaml` 的字体名对不上；手动安装的回到第 2 步 |
| 界面仍是英文 | 文本没覆盖成功。确认盖的是 `mods\` 而不是 `mods\mods\`（多套一层最常见） |
| 卸载后仍是中文 | 还原用错了备份。重跑选 `2`；仍不行用 `-Uninstall -Backup <备份目录名>` 指定 |
| 启动即报错 / 闪退 | 多半是“覆盖了文本但没放字体”，照第 2 步补齐两个字体 |
| 出现 `label-xxx` 键名 | 补丁与游戏版本不匹配（游戏升级过）。卸载后换对应新版本的补丁 |
| 影响联机 / 存档吗 | 不改地图数据，联机与旧录像兼容；存档在 `%APPDATA%\OpenRA`，补丁不碰。服务器若装文件校验插件，理论上可能判定为改文件 |
| 杀毒软件报毒 | 安装器是未签名 PowerShell 脚本。不放心就走手动安装，效果完全相同 |

## ⑤ 其他

- **包里有什么**：`setup.ps1` 入口 · `bin\` 脚本与哈希清单 · `files\mods\` 208 个文本 · `fonts\` 两个中文字体 · `README.md` 逐文件说明 · 两个许可证。208 个文件的逐个作用见 `README.md` 附录 A。
- **别单独挪动 `bin\`**：`setup.ps1` 按相对路径找它。
- **只适配 `playtest-20261026`**：引擎升级后先卸载旧补丁再更新。
- **字体**：Noto Sans SC 全量字形约 20 MB，换来不依赖本机字体；个别 UI 缩放档位行高可能略挤。
